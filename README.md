# Task Manager ✅

A simple task management app built with React to organize daily tasks and track progress.

## Features

- Add tasks using Enter or the Add Task button
- Prevent duplicate tasks
- Mark tasks as completed or undo completion
- Edit and delete tasks
- Confirm before deleting tasks
- Search tasks by title
- Filter tasks by All, Active, and Completed
- Track completed and remaining tasks
- View progress with a progress bar
- Save tasks using localStorage

## Technologies

- React
- JavaScript
- CSS
- Vite
- localStorage
